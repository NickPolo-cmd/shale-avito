# Фид автозагрузки Авито — SHALE

Здесь лежит то, что Авито забирает автоматически: XML-фид объявлений и фотографии к ним.

- `avito.xml` — фид автозагрузки. Эта ссылка вставляется в Авито:
  «Автозагрузка → Настройки → Настроить загрузку по ссылке».
- `galereya.html` — все объявления с фотографиями, чтобы проверить глазами.
- `photo/` — фотографии, по одной папке на объявление.

Компания SHALE (ООО «ДЖ-Групп»), Санкт-Петербург и Ленинградская область.
Строительство домов и отделка с 2013 года.
